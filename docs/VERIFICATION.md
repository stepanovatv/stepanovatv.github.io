# Проверка MVP

Проверки выполнены 17–18 сентября 2026 года на Apple Silicon macOS со Swift 6.2.3.

## Автоматические проверки

- Web: `npm test` — 15 тестов. JSON, конфигурация, busy/free, миграция, IANA/DST, границы календаря, соседние исходные даты, cache busting, ошибки загрузки.
- Swift Core: `bash macOS/test.sh` — 14 тестов. Модель, календарь, сериализация, история действий, черновик, GitHub GET/PUT, конфликты SHA до записи и между GET/PUT, 422, ошибки сети и авторизации.
- Swift Editor: тот же скрипт — 5 тестов группового редактирования. Единое состояние ячеек, повторное посещение, пересечение дней, один Undo/Redo на жест, диапазон с исключённым концом и запрет изменений во время сетевой операции. Тестовые экземпляры не имеют remote snapshot, поэтому не пишут локальный черновик и не обращаются к Keychain или GitHub.
- Debug и release сборки прошли. Release `.app` имеет локальную ad-hoc подпись, проверенную `codesign --verify --deep --strict`.

## Проверка интерфейсов

В браузере проверены desktop и мобильная ширина 390 px: автоматическая зона Asia/Tbilisi, ручная Europe/Moscow, изменение времени без reload, недельная навигация, выбор и повторное снятие выделения, нижняя панель подробностей, клавиатурные стрелки и подсветка строки/столбца.

В macOS проверены запуск `.app`, реальное чтение нового JSON из ветки master, сетка Оренбурга, переключение ячейки, активация кнопки публикации, ⌘Z и возврат к состоянию без изменений. Существующий черновик открытого пользователем редактора сохранён.

Физическое mouse-drag через средство UI-автоматизации не удалось выполнить: оно вернуло `noWindowsAvailable`. Логика жеста покрыта пятью тестами редактора; физический drag и полный VoiceOver-сценарий остаются пунктами ручной приёмки. Матрица отдельных Safari/Firefox/Edge и реальных iOS/Android-устройств не прогонялась.

## Публикация

Изменения размещены в `master` репозитория `stepanovatv/stepanovatv.github.io`. GitHub Pages отдаёт новую `schedule.html`; её JSON побайтово/семантически сопоставлен с опубликованным файлом. В браузере публичная страница показывает 182 окна текущей недели, из них 72 занятых. В двух перенесённых неделях всего 144 занятых окна.

Главная страница и 24 прочих исходных файла блога сохранены без изменения. Jekyll продолжает работать; добавлен только список исключений для файлов разработки.

Реальный PUT из macOS-приложения и сохранение PAT в Keychain не выполнялись: владелец решил настроить token позднее. GET к реальному репозиторию проверен; PUT и конфликты проверены через URLProtocol без внешних записей. Приложение не подписано Developer ID и не notarized; архив предназначен прежде всего для текущего Mac (Apple Silicon, macOS 14+).
